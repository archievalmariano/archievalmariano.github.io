# Field Notes — manuscript privacy

This directory holds the **Field Notes** content collection ("From the
Margins"). Files whose names start with `_` (like this one) are ignored by
Astro's content collections, so this note never becomes a page.

**Unpublished manuscripts must NOT be committed to this repository.**

This portfolio repository may be publicly accessible. Astro's `draft` flag and
the collection publish gate exclude unpublished work from the *generated site*,
but they do **not** make committed *source files* private. Therefore keep real,
in-progress entries **outside the public repository** until their publication is
approved, and add an entry here only when it is ready to publish. Synthetic
fixtures for gate testing live in `test/fixtures/desk/`, not here.
